# JavaScript Todo Application

A Todo Application developed as part of my JavaScript learning journey with NxtWave.

## Overview

This project helped me practice JavaScript concepts by working with a dynamic Todo interface and browser Local Storage.

## Concepts Practiced

- DOM Manipulation
- Event Handling
- JavaScript Arrays and Objects
- Local Storage API
- Retrieving stored data using `localStorage.getItem("todoList")`
- Inspecting stored data using Chrome DevTools Console
- HTML5 and CSS3

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Learning Outcomes

- Practiced updating HTML elements dynamically.
- Improved my understanding of browser storage.
- Learned to inspect stored Todo data using Chrome Developer Tools.
